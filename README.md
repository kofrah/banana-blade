# Banana Blade As A Service

**BANANA BLADE slice your photo.**

撮影した写真やアルバムの画像を、立体的なバナナブレイドで切断するスマートフォン向けWebアプリです。切断した結果を、文字とブレイドアイコン入りのPNGとして保存・共有できます。

## 主な機能

- カメラ撮影、インカメラ・アウトカメラの切り替え、アルバムからの画像選択
- 1〜3本のブレイドによる自動切断
- ランダムな切断角度と、破片の回転・落下アニメーション
- 通常ブレイドとレアブレイド、レア時の特殊エフェクト
- シャッター音・切断音
- 結果画像の保存・共有、再撮影
- Xへの写真共有（`#bananablade`付き）。対応端末では共有メニューでXを選択。非対応環境では画像を保存し、ハッシュタグ入りの投稿画面で手動添付

通常のNext.js本体ではなく、vinextを使用しています。物理エンジンは導入せず、破片の動きを独自に計算しています。

## データの扱い

写真の取り込み・切断・結果画像の生成はブラウザ内で行います。アプリには写真をサーバーへアップロード・保存する処理はありません。データベース、アカウント登録、AIによる画像処理も使用していません。共有操作では、ユーザーが選んだ共有先に結果画像を渡します。

カメラは起動時の案内を確認した後に使用許可を求めます。マイクは使用しません。

## ローカル開発

Node.js **22.13.0以上**とnpmが必要です。

```sh
npm ci
npm run dev
```

ターミナルに表示されたローカルURLをブラウザで開いてください。

カメラ利用には、ブラウザのカメラ権限とHTTPSまたはlocalhostが必要です。スマートフォンからLAN内の開発サーバーへアクセスする場合は、HTTPSを用意してください。3D表示にはWebGL対応ブラウザが必要です。共有機能の可否はブラウザによって異なります。

### コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 配信用にビルド |
| `npm start` | ビルド後の成果物をWranglerでローカル実行 |
| `npm run lint` | Oxlintによる静的解析 |
| `npm run format` | Oxfmtによる整形 |

## ホスティング

現在はSites用プラグインとCloudflare用Viteプラグインを組み合わせた構成です。D1・R2は未使用です。

別のホスティングへ移行する際は、その環境に合わせてビルド・実行・デプロイ設定を調整してください。`vite.config.ts` が `.openai/hosting.json` を読み込んでいるため、このファイルだけを削除するとビルドに影響します。
